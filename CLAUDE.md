# Claude Code instructions

The canonical repository instructions are in [AGENTS.md](AGENTS.md). Read and follow that file before editing code.

Use these current references when the task needs more context:

- Setup, commands, data model, and security: [README.md](README.md)
- How a subsystem actually works: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Product guardrails and open backlog: [docs/ROADMAP.md](docs/ROADMAP.md)
- Migration runbooks: [docs/MIGRATIONS.md](docs/MIGRATIONS.md)
- Cross-project contracts: `docs/integrations/`

AGENTS.md carries the full map of the documentation. There are six files; do not add a seventh without a subject that has no home in them.

Keep temporary plans, review diffs, transcripts, and session reports out of the repository. Durable shared rules belong in `AGENTS.md`; task history belongs in Git or the issue tracker.
